# RibbonTrace 缎带路径台

用照片留存礼品缎带的布置和测量。标尺用毫米每像素记录，路径由实际选取的原片点组成。

1. 打开注明为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP、WebP。
2. 在原片用「加路径点」按顺序标点，也可以逐行输入 X,Y。设置标尺和原片采样步长，再保存。
3. 核对已存路径长度、沿路径亮度与原片RGB点读。沿标点之间默认用直线计算距离。
4. 在「相邻点对」中选一对点，或用「选段」模式点近该段，再点「重走这一段」。助手只搜索点连线两侧各28 px的走廊，沿同一条蓝缎带的两条可见边找中心；只衔接一处两边同带露出、长度不超过24 px的遮挡。遮挡太宽或两侧边/走向对不上时会提示“还不能续”，不会硬补。保存后可「切回手填直线」。
5. 重走结果会分别统计实见长度和遮挡估段长度；CSV/JSON读数用 `kind=visible|occluded`、`estimated` 和中文 `evidence` 区分，遮挡处的 `luma` 留空，不把上层缎带颜色当作该带实测。PNG校样用青色实线和品红虚线标出同一估段；设置随卡片保存，带 `#card=<id>` 重开可复核。
6. 下载实际原坐标的CSV、PNG校样或证据ZIP，或送原图去照片准备。

`docker compose up --build -d --wait` 默认本机端口19917。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后执行 `./start.sh`。数据保存在独立卷或本地数据目录。
